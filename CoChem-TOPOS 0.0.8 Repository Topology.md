## **⚠️ The Filesystem Air-Gap Policy**

To maintain pristine repository health and prevent the accidental uploading of proprietary geometries or massive wavefunction files to GitHub, the following dynamically generated data directories and artifacts are permanently excluded from this repository via .gitignore:

* $HOME/CoChem\_Artifacts/ (The centralized data vault managed by CoChem-CORE)  
* cochem\_system\_config.json (The runtime-generated hardware registry)  
* landscape.h5 / ensemble.h5 (Gigabyte-scale SWMR topological databases)  
* \*.gbw / \*.tmp / \*.out (Massive scratch wavefunctions and OpenMPI execution logs)  
* TOPOS\_Supporting\_Information.tex and TOPOS\_FAIR\_Archive.zip (Generated by Stage 5.0)
