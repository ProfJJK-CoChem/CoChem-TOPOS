# Local isolated BASE/TOPOS compatibility evidence

These files retain actual local Linux checks against the candidate source hashes
in `validation.json`. The input is public test water, not a student project.
No credentials, licensed engine binaries, model weights or private student
evidence are included.

- `boundary-evidence-final.json`: the genuine canonical TORQ installation was
  verified separately; changed source, installed code, wheel, receipt, revision
  and sidecar were rejected. Original bytes were restored and reverified.
- `native-evidence.json`: actual BASE producer and installed TOPOS receiver,
  mandatory BASE execution authority, real xTB 6.7.1 GFN2 single point and
  precancellation. Native scientific validation remains `human-review`.
- `native-snapshot/`: unchanged committed native snapshot, including HDF5 record,
  request and raw xTB input/output. Its manifest and the artifact inventory retain
  the exact observed bytes. Paths within historical records describe that run.
- `producer-handoff/` and `source.xyz`: original BASE handoff and source bytes.
- `validation.json`: exact scope, source/wheel identities and test outcomes.
- `compatibility-profile.xml`: complete profile, 2,824 passed and 43 optional
  skips. It loaded the earlier GPU fault-test fixture; its exact source hash and
  the subsequent final 11-case GPU check are retained in `validation.json`.
- `metadata-and-sidecar-tests.xml` and `final-gpu-tests.xml`: final focused
  follow-ups; no scientific thresholds or mandatory parser/source gates changed.
- `artifact-inventory.json`: SHA-256 and byte count of each retained file.

This is bounded local xTB and packaging acceptance. It does not establish
ORCA/CFOUR, Actions, a student Codespace, full SRS conformance, scientific
publication readiness or a completed student pilot. The historical combined
TOPOS helper/workflows and BASE's final outer installer/adapter must be
qualified separately.
